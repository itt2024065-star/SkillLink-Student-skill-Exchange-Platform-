# SkillLink - Student Skill Exchange Platform

SkillLink is a web application designed for university students to exchange skills, learn from each other, and collaborate based on their academic and creative interests.

## Key Features

1. **Home Page**
   - Introduction to the SkillLink platform
   - Navigation to the main sections
   - Attractive hero section

2. **Skill Profiles and Skill Dashboard**
   - Students can explore available skills
   - Skill information is displayed in an organized way

3. **Skill Search and Filtering**
   - Students can search for skills
   - Skills can be organized according to categories and levels

4. **Login Page**
   - User login interface
   - User-friendly authentication form

5. **Contact Page**
   - Contact form for submitting messages and inquiries

6. **Interactive User Interface**
   - Responsive design
   - Interactive elements using JavaScript
   - Modern navigation and page layouts
