Skill-Link -- Student Skill Exchange Platform

Skill-Link is a peer-to-peer skill exchange platform designed for
university students. It allows students to discover other students,
share their skills, learn new skills, and manage skill-swap requests
through a simple web interface.

Project Overview

The main idea of Skill-Link is to connect students who can teach one
skill with students who want to learn that skill.

For example:

A student who knows Java can teach Java.

Another student can offer Web Design in exchange.

Students can discover suitable peers and send skill-swap requests.

The project was developed as a front-end web project using HTML, CSS,
and JavaScript.

Main Features

1. Home Page

Introduces the Skill-Link platform.

Provides navigation to the main sections.

Presents the purpose of the platform.

2. Browse Skills

Displays available skills.

Helps students explore skills that can be taught or learned.

Provides an easy way to find potential peer tutors.

3. Dashboard

The dashboard provides a personalized student view, including:

Student profile information

University information

Student badges

Badge progress

Recommended peers

Skill information

Skill-swap requests

Accept and decline actions

4. Login Page

Provides a student login interface.

Connects users to the platform experience.

5. Contact Page

Provides a contact form/interface for users who need to contact the
platform.

6. Interactive JavaScript Features

JavaScript is used for interactive parts of the website, including:

Active navigation highlighting

Skill ticker

Smooth scrolling

Badge modal

Skill filtering

Skill matching

Swap request modal

Contact form interaction

Login form interaction

Swap request table

Badge progress

How to Run the Project

Option 1 -- VS Code Live Server

Open the project folder in Visual Studio Code.

Open index.html.

Right-click inside the HTML file.

Select Open with Live Server.

The website will open in the browser.

Option 2 -- Browser

You can also open index.html directly in a web browser.

Git and GitHub

This project uses Git for version control.

Check the current status

Add changes

git add .

Create a commit

git commit -m "Update project"

Push changes to GitHub

git push origin main

Pull the latest changes

git pull origin main

Before pushing your work, it is recommended to pull the latest changes
if other team members may have updated the repository.

Team Collaboration

For team development:

Pull the latest project from GitHub.

Make your changes.

Test the website locally.

Check that images and file paths work correctly.

Save all files.

Run git status.

Add the changes with git add ..

Commit the changes.

Push the commit to GitHub.

Important Notes

Keep HTML, CSS, JavaScript, and image files in their correct
folders.

Use relative image paths such as images/img1.jpg.

Do not rename files without updating their references in the code.

Test all pages after making major changes.

Keep the shared style.css file consistent across pages.

Pull changes from GitHub before starting work if the repository is
being edited by multiple team members.
